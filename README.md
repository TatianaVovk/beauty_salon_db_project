# Проект базы данных "Салон красоты"

📌 Учебный проект по моделированию и созданию реляционной базы данных для управления салоном красоты.

---

## 🗂 Состав проекта

- `schema/beauty_salon.mwb` — модель базы данных в формате MySQL Workbench.
- `schema/beauty_salon.sql` — SQL-скрипт для создания структуры БД.
- `screenshots/er_diagram.png` — ER-диаграмма со связями таблиц.

---

## 📋 Описание

База данных предназначена для хранения и управления следующими сущностями:

- **Клиенты**: личные данные, история посещений, скидки
- **Сотрудники**: мастера, их опыт, должность, медицинская книжка
- **Услуги**: стоимость, мастер, офис
- **Записи**: история приёмов, дублирующие сотрудники
- **Материалы и расходники**: склад, заказы, использование
- **Филиалы**: распределение персонала по офисам

---

## 🧰 Технологии

- MySQL
- MySQL Workbench

---

## 🧪 Назначение

Проект создан в учебных целях для практики в проектировании, нормализации и визуализации баз данных. Может использоваться как база для автоматизации бизнес-процессов небольшого салона красоты.
